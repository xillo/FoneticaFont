# Changelog — Fonetica

## [1.1.0] — 2026-11-25

- Inverted the accented-vowel scale logic from version 1.0.0.
- Enlarged grave-accented lowercase `è` and `ò`.
- Reduced acute-accented lowercase `é` and `ó`.
- Retained family name **Fonetica** and author metadata **Davide Perillo**.
- Rebuilt all four styles: Regular, Bold, Italic, Bold Italic.
- Regenerated OpenType desktop fonts (`.otf`) and WOFF2 web fonts (`.woff2`).
- Updated preview image, source build script and documentation.

## [1.0.0] — 2026-11-21

- Initial release under the **Fonetica** family name.
- Author metadata identifies **Davide Perillo**.
- Distinctly compact grave-accented lowercase `è` and `ò`.
- Enlarged acute-accented lowercase `é` and `ó`.
- Four styles: Regular, Bold, Italic, Bold Italic.
- OpenType desktop fonts (`.otf`) and WOFF2 web fonts (`.woff2`).
- Source build script, font preview and licensing/attribution included.
